# Contributing

Thank you for improving Signal & Sense. Focused issues and pull requests are welcome.

## Content corrections and examples

- Include the filter name and the explanation or example that needs attention.
- Provide a reliable source when correcting a definition, formula, or market convention.
- Keep English and Cantonese explanations aligned in meaning and level of detail.
- Prefer practical examples and common misreads over additional jargon.
- Never present illustrative chart values as real market performance or investment advice.

## Development

1. Fork the repository and create a focused branch.
2. Install exact dependencies with `npm ci`.
3. Keep changes scoped to one topic or fix.
4. Run `npm run build` and `npm run lint` before submitting.
5. Include a short description of the change and, for visual updates, a screenshot when useful.

## Questions and support

Open a GitHub issue for bugs, unclear explanations, accessibility problems, or suggestions. Avoid posting credentials, API keys, personal account data, or proprietary market data.
